Definition of Done:
Before code may be merged into the main GitHub Repo it must first be tested physically on the Rover, and work correctly. This process cannot be automated with a CI/CD pipeline because it must be physically tested in person on the rover. 

The Contribution Norm:
Each member's work lives in the Group GitHub which will eventually be merged into the DAM Robotics GitHub after it has been tested thoroughly. When code is pushed to the group GitHub it should be tested on the following Saturday. Code that does not compile or overwrites someone else's active development should not be pushed to the repo.
